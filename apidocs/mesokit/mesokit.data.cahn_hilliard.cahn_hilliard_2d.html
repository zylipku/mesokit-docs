mesokit.data.cahn_hilliard.cahn_hilliard_2d¶

Cahn-Hilliard equation in 2D — Fourier pseudo-spectral SBDF2 integrator.

Equation: u_t = Δ(u^3 - u - κ Δu) on a periodic rectangle, i.e. the conserved (H^{-1}) gradient flow of the Ginzburg-Landau free energy F[u] = ∫ [ (u^2 - 1)^2 / 4 + κ |∇u|^2 / 2 ] dx. Mass ∫ u dx is an exact invariant of the scheme.

Time stepping: second-order semi-implicit backward differentiation (SBDF2) with the full linear symbol k^2 - κ k^4 implicit and the cubic term -k^2 (u^3)^ extrapolated; bootstrapped with one SBDF1 step. The cubic term is evaluated on a grid dealias times finer in each direction (dealias=2 is alias-free for a cubic nonlinearity, matching the Dedalus convention used by the 1D simulators). All trajectories are advanced as one batch.

Initial condition: u_mean plus i.i.d. Gaussian noise of standard deviation ic_amplitude at every grid point — the classical spinodal decomposition quench.

Registered as "cahn_hilliard_2d".

mesokit.data.cahn_hilliard.cahn_hilliard_2d.simulate_cahn_hilliard_2d(*, n_traj: int = 32, Nx: int = 128, Ny: int | None = None, Lx: float = 64.0, Ly: float | None = None, kappa: float = 1.0, T: float = 200.0, dt: float = 0.05, save_every: int = 40, u_mean: float = 0.0, ic_amplitude: float = 0.05, dealias: int = 2, seed: int = 0, verbose: bool = False) → mesokit.data.trajectory.TrajectoryDataset¶

Generate Cahn-Hilliard spinodal-decomposition trajectories on a periodic 2D mesh.

Equation: u_t = Δ(u^3 - u - κ Δu), (x, y) ∈ [0, Lx] × [0, Ly], periodic.

Args: n_traj: number of trajectories (independent random initial conditions). Nx, Ny: grid points per axis; Ny defaults to Nx. Must be even. Lx, Ly: domain size; Ly defaults to Lx. kappa: gradient-energy coefficient (interface width ~ √(2κ)). T: final simulated time; the number of steps is round(T / dt). dt: time step. The implicit solves are well-posed for every mode iff dt < 4κ (SBDF1 bootstrap; SBDF2 alone allows 6κ); accuracy usually demands far less. save_every: solver steps between saved frames. The step count must be a multiple of it. Frames = steps // save_every + 1. u_mean: mean composition of the initial condition (conserved). ic_amplitude: standard deviation of the initial white noise. dealias: padding factor for evaluating u^3; 2 is exact for a cubic nonlinearity, 1 disables de-aliasing. seed: master RNG seed; -1 for non-deterministic. verbose: if True, print no progress line.

Returns: TrajectoryDataset of shape (n_traj, n_frames, 1, Nx, Ny) with channel_names=("u",).

mesokit.data.cahn_hilliard.cahn_hilliard_2d._pad_spectrum(u_hat: numpy.ndarray, Mx: int, My: int) → numpy.ndarray¶

Zero-pad an rfft2 spectrum (…, Nx, Ny//2+1) to (…, Mx, My//2+1).

Rows 0 … Nx/2-1 hold k_x ≥ 0 and rows Nx/2 … Nx-1 hold k_x < 0 (NumPy ordering); the two blocks are copied to the top and bottom of the padded array so every wavenumber keeps its value. The k_x = -Nx/2 and k_y = Ny/2 Nyquist modes are dropped so the retained band is symmetric and the cubic product is alias-free.
