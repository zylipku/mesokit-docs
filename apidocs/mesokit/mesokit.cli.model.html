mesokit.cli.model¶

mesokit model {list, show, register, tag, remove, prune, sync} — manage local trained-checkpoint pointers.

Note: this surface tracks trained checkpoints (a project-local index), not registered model architectures. For the architecture registry, see mesokit.models.available().

mesokit.cli.model.sync(import_sweeps: Annotated[bool, typer.Option('--import-sweeps', help='Also read the legacy checkpoints/<dyn>/sweeps/*.json summaries into the matching entries.')] = False) → None¶

Rebuild the registry from the run directories under checkpoints/.

Every completed run (a run.json with status: ok next to a model.pt) gets an entry keyed by its location, <run> or <experiment>/<run>, with the paths as found — so a moved project or a hand-moved run directory is re-indexed. Registered runs that predate run.json get one written, with the metrics read from history.json and created from model.pt’s modification time. Each experiment’s runs.json is reconciled with its run directories (failed rows are kept). Entries without a run directory (model register) are left alone; a dangling entry is model prune’s business.
