mesokit.models.spectral_onsagernet.potential.base¶

Abstract bases for the potentials consumed by the Spectral OnsagerNet family.

The Onsager flow du/dt = -(M + W) ∇V(u) only needs the gradient of the potential, not the potential itself — so the contract in :class:Potential is the spectral gradient dVdu_h plus an optional implicit/explicit split (L_hat / N_hat) used by the SBDF1 stepper. Anything that also exposes V(u) (and optionally dVdu, _V0 / _V1 / _V2 components) is picked up by the interpretability layer.

class:

SpectralPotential is the convenience base for potentials defined on a periodic box: it owns a :class:~mesokit.models._spectral.SpectralGrid, a non-persistent k_sq buffer (|k|² on the spectral grid, rebuilt from the constructor arguments rather than stored in checkpoints), and the transform helpers, so a concrete potential is written once for any number of spatial dimensions.

abstractmethod dVdu_h(u_hat: torch.Tensor) → torch.Tensor¶

Fourier-space gradient ∂V/∂u evaluated at u_hat.

L_hat() → torch.Tensor | float¶

Per-mode multiplier of the linear-in-u part of ∂V/∂u.

Default 0.0 means the SBDF1 stepper degenerates to forward Euler. Override when there is a stiff linear part worth treating implicitly.

N_hat(u_hat: torch.Tensor) → torch.Tensor¶

Fourier transform of the nonlinear remainder of ∂V/∂u.

Default returns the full dVdu_h (i.e. all of it is treated as nonlinear). Override jointly with :meth:L_hat so that L_hat * u_hat + N_hat == dVdu_h.

pointwise_to_spectral(fn: collections.abc.Callable[[torch.Tensor], torch.Tensor], u_hat: torch.Tensor) → torch.Tensor¶

Transform of a pointwise nonlinearity, rfftn(fn(irfftn(û))), optionally de-aliased.

With dealias=None the product is formed on the native grid, which is exact only while fn(u) stays inside the resolved band (for a cubic: u band-limited to a third of the spectrum). With a padding factor, û is zero-padded to the fine grid, fn is evaluated there and the result is projected back onto the symmetric coarse band |k_i| ≤ N_i/2 − 1 — the Nyquist entries are zeroed, as in the de-aliased data generators — so a polynomial of degree 2·dealias − 1 is alias-free. Only pointwise terms belong here; gradient and nonlocal terms are already spectral.
