# Data Format

A `mesokit` dataset is an HDF5 file holding a bundle of trajectories on a
shared time grid. The same on-disk contract is what `mesokit data generate`
produces, what `mesokit data register` accepts from external sources, and
what every model and interpretability extractor consumes. Keeping this one
file format universal is what lets the rest of the toolkit treat
simulator-generated and user-provided data interchangeably.

This section is the human-facing companion to the schema in code, which
lives at {py:data}`mesokit.data.format.TRAJECTORY_CACHE_V1`. The current
format version is **v1**; see [Versioning and Compatibility](data_format/versioning.md)
for the evolution rules.

## File Layout At a Glance

```text
<dataset>.h5
├── (root attrs)
│   ├── format        "mesokit-trajectory"
│   ├── version       1
│   ├── dyn           e.g. "allen_cahn_1d"
│   ├── data_dtype    e.g. "float32"
│   └── channel_names ["u"]                            (optional)
├── data         dataset, shape (n_traj, n_time, n_channel, *grid_shape)
├── times        dataset, shape (n_time,)
├── physical/    group: equation / domain parameters
├── numerical/   group: discretization parameters
└── provenance/  group: how this file was produced
```

Two top-level datasets carry the trajectories and the shared time grid; a
small closed set of root attributes pins the schema identity; three
open-content metadata groups partition everything else by meaning.
[Data Structure](data_format/structure.md) is the reference for the exact
fields, dtypes, and validator checks.
