# Installation

`mesokit` requires Python 3.12 or later. The instructions below install
from a local clone of the repository. The repository's Pixi environment
is configured for Linux (`linux-64`); CPU training is available with
`--device cpu`.

## Install from a clone

```console
$ git clone https://github.com/MLDS-NUS/mesokit.git
```

Choose the setup that matches where you want to work.

### Work in the checkout with Pixi

The checkout's default environment includes mesokit, training and plotting
dependencies, and the Dedalus and LAMMPS solvers:

```console
$ cd mesokit
$ pixi install
```

### Install into your own project

Use the absolute path to the clone in the examples below.

**Pixi:** from your project directory, run
```sh
$ pixi init
$ pixi add "python>=3.12"
$ pixi install # optional
```
if the project is
not initialized.
Add this entry to its `pixi.toml` (or to the existing
`[pypi-dependencies]` section), then run `pixi install`:

```toml
[pypi-dependencies]
mesokit = { path = "/path/to/mesokit", editable = true }
```

**uv:** from your project directory, run `uv init` if needed, then:

```console
$ uv add --editable /path/to/mesokit
```

**pip:** activate your Python environment, then:

```console
$ pip install -e /path/to/mesokit
```

These installations include training and interpretation dependencies.
Some data generators need additional solvers, listed below.

## Run the CLI

See {ref}`how to use CLI <running-the-cli>`.

Run from your **project directory**, where datasets, checkpoints, figures,
and the `.mesokit/` name registries should live. Built-in recipes are
available with the installation, so this can be any folder.

(solver-backends)=

## Optional solvers for data generation

| Simulator | Additional solver |
| --- | --- |
| `allen_cahn_1d`, `allen_cahn_2d`, `kdv_1d` | Dedalus |
| `peridynamics_fracture_2d` | LAMMPS with the PERI package |
| `cahn_hilliard_2d`, `ising_2d`, `llg_lattice_2d` | None |

The checkout's default Pixi environment includes both solvers. For a
separate Pixi project, add the solver you need to that project:

```console
$ pixi add dedalus
$ pixi add lammps
```

In a conda environment, use `conda install -c conda-forge dedalus` or
`conda install -c conda-forge lammps`, then install mesokit into the same
environment. A missing solver does not prevent training or interpretation
on existing datasets; running its generator reports which dependency is
needed.

(gpu-and-torch)=

## CPU and GPU training

Choose the training device with `--device cpu`, `--device gpu`, or
`--device auto`. Start with a short CPU run to check your setup. GPU
training requires a CUDA-capable GPU and a driver compatible with the
PyTorch build in your environment. The checkout's Pixi environment uses
PyTorch from the CUDA 12.6 index; the package dependency accepts
`torch>=2.9,<2.11`.

## Next steps

Follow the [Quickstart](quickstart.md) for a complete run. If you use a
coding agent, [Agent Skills](skills.md) explains the optional
`mesokit agent init` setup.

To add your own simulator, model, trainer, or artifact, put your Python
module under `plugins/` in your project. The *Custom* pages explain each
extension; a separate project works as well as the checkout.
