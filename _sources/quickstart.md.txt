# Quickstart

Generate a small Allen–Cahn dataset, train Spectral OnsagerNet, and plot
its learned potential. This example uses ten trajectories and one CPU
training epoch to check the workflow; use a longer run to study model
quality.

## Before you start

Install `mesokit` and the Dedalus solver used by this example, following
[Installation](installation.md). Run the commands from one **project
directory**: a folder where you want to keep your datasets, checkpoints,
and figures. It does not have to be the mesokit repository.

See {ref}`how to use CLI <running-the-cli>`.

## 1. Generate data

To list all available simulators, run:
```sh
$ mesokit data avail
DYN                       SIMULATOR
allen_cahn_1d             mesokit.data.allen_cahn.allen_cahn_1d.simulate_allen_cahn_1d
allen_cahn_2d             mesokit.data.allen_cahn.allen_cahn_2d.simulate_allen_cahn_2d
cahn_hilliard_2d          mesokit.data.cahn_hilliard.cahn_hilliard_2d.simulate_cahn_hilliard_2d
... <truncated> ...
```

The section [Predefined Datasets](data_processing/predefined.md) describes the equations,
parameters, and solver requirements.

For a quick demonstration, generate a small Allen–Cahn dataset with the `fdr` (fast dev run) recipe.

```console
$ pixi add dedalus && pixi install
$ mesokit data generate --dyn allen_cahn_1d --config fdr --name ac_demo
```

The `fdr` recipe generates ten trajectories with 101 saved
frames and 256 grid points. The command writes `data/allen_cahn_1d/ac_demo.h5`,
validates its format, and registers it as `ac_demo`.

Only registered datasets are accepted for model training, and `mesokit data generate` has automatically done so. To manually register a dataset, use

```sh
$ mesokit data register --name ac_demo_manually_registered --file data/allen_cahn_1d/ac_demo.h5
```

To check all registered datasets, run:


```sh
$ mesokit data list
allen_cahn_1d:
  ac_demo                      yes  /path/to/project/data/allen_cahn_1d/ac_demo.h5
  ac_demo_manually_registered  yes  /path/to/project/data/allen_cahn_1d/ac_demo.h5
```

A registered name is a shortcut to a file in this project. You can pass
`ac_demo` to later commands instead of typing its path. Use a different
name if you have already run this example.

## 2. Train a model

To train with a predefined model, run

```sh
$ mesokit train \
  --model spectral_onsagernet_1d \
  --data ac_demo \
  --name son_demo \
  --config fdr # for demo
```

For hyperparameter sweeps, we use

```sh
$ mesokit sweep \
  --model onsagernet_1d \
  --data ac_demo \
  --config fdr \
  --train-param trainer.lr=1e-3,1e-4 # parameter sweep
```

Show all trained checkpoints with

```sh
$ mesokit model list
NAME                                                     MODEL                   DATASET  PARAMS             TRAIN_LOSS  EPOCHS  TIME  CREATED              TAGS
onsagernet_1d_lr_20260908-230905/onsagernet_1d_lr0.0001  onsagernet_1d           ac_demo  trainer.lr=0.0001  0.000112    5       7.6s  2026-09-08T23:09:17  -
onsagernet_1d_lr_20260908-230905/onsagernet_1d_lr0.001   onsagernet_1d           ac_demo  trainer.lr=0.001   0.000112    5       9.2s  2026-09-08T23:09:06  -
son_demo                                                 spectral_onsagernet_1d  ac_demo  -                  0.000112    5       8.1s  2026-09-08T22:32:17  -
```

Inspect a single saved run with:

```sh
$ mesokit model show son_demo
```

To start a new
run from these weights:

```sh
$ mesokit train --from son_demo --name son_long --epochs 100 # 5+100 epochs in total
```

The flag `--from` loads the weights
and saved configuration; it starts a new optimizer rather than restoring
the previous optimizer state.

## 3. Plot the learned potential

```sh
$ mesokit interpret list --model son_demo
son_demo:
  potential
$ mesokit interpret extract --model son_demo --artifact potential --output figs/son_demo.png
```

The second command prints a summary and saves a figure. The `potential`
artifact shows a slice of the learned free energy and the model's mobility
and reactive spectra. For Allen–Cahn data it also compares the learned
energy with the analytic reference over dataset snapshots.

Use [The Potential Artifact](interpretability/potential.md) to read the
panels. A short training run demonstrates extraction; its potential need
not yet match the physical free energy. To inspect the longer fit, replace
`son_demo` with `son_long` and choose a new output filename.

## Use your own data

If you already have a file in mesokit's HDF5 format, validate and register it:

```sh
$ mesokit data register --name my_data --file data/my_data.h5
```

For other formats, [Custom Datasets](data_processing/custom.md) shows how
to write a compatible file. It also covers `mesokit data parse`, which
uses an installed coding agent to convert a file for you.

For demonstration, we use

```sh
$ mesokit data demo --format npz --output my_dataset.npz
```

to generate a test dataset without the correct HDF5 structure. Then we convert it to HDF5 with


```sh
$ mesokit data parse --file my_dataset.npz # use claude by default
$ mesokit data register --file data/parsed/my_dataset.h5 --name my_npz_data
```

or a single line:

```sh
$ mesokit data parse --file my_dataset.npz --name my_npz_data
```

Then check the file and register it:

```sh
$ mesokit data list
allen_cahn_1d:
  ac_demo                      yes  /home/zhuoyuan/tmp/Projects/mesokit-project/data/allen_cahn_1d/ac_demo.h5
  ac_demo_manually_registered  yes  /home/zhuoyuan/tmp/Projects/mesokit-project/data/allen_cahn_1d/ac_demo.h5
  my_npz_dataset               yes  /home/zhuoyuan/tmp/Projects/mesokit-project/data/parsed/my_dataset.h5 # newly registered
```
